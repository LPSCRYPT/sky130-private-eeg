# QC01 verifier contract

Statement: for the **exact signed ordered roots** at indices 0…N−1 under the expected 128-bit challenge, `total` is the number of windows having 500 present slots and at most four signed-24 endpoint codes. The approved circuit key fixes the sample encoding, Poseidon parameters, arithmetic and predicate. A valid proof means those arithmetic constraints held for openings; it is not a signature from an ADC. The recipient supplies `N`, challenge, recorder public key and Groth16 VK independently. A real recipient must issue an unpredictable challenge per session, expire it and mark it consumed after acceptance. The standalone verifier is stateless and will intentionally verify the same artifact twice if asked with the same expectation.

## Encoding

Integers and canonical scalar-field elements are little endian. Public nonce spelling is 32 hex digits in *wire-byte order*; field elements occupy 32 bytes. Ed25519 signatures occupy 64 bytes. Each Groth16/BLS12-381 proof uses arkworks canonical compressed group encoding (192 bytes). Checked decoding rejects noncanonical fields/groups, trailing bytes and out-of-order indices. See `src/{wire,session,circuit}.rs` for executable formats.

- Manifest: ASCII `EEG-MANIFEST`, byte `01`, ASCII `QC01`, challenge[16], N:u16, followed by N × (index:u16, window_root:Fr) and the device signature over everything before that signature. N ranges from 1 to 65,535. Demo recorder keys are host generated; untrusted host-selected manifests are **not** hardware evidence.
- Each hidden count commitment at position `i` is the first element of `Permute([0x43515401 + (i << 32) + (prefix << 48), nonce, salt_i])`. Independent unpredictable field salts per position. Window roots use a different domain. The verifier constructs exactly five public inputs per proof: nonce, index, signed window root, previous count commitment, next count commitment.
- Bundle: ASCII `EEG-PROOF`, byte `01`, complete signed manifest, salt at position zero, first count commitment, N × (next count commitment, proof), final salt, final count:u16. Only the zero and final count commitments are opened. Adjacent windows share a commitment to the same private count; no individual decision bit is exported. No counter wrap: the circuit constrains `before` and `index − before` to 16 bits and increments by a Boolean, with index ≤ N−1. Bundle length is `207 + 258*N` bytes, excluding independent identity/VK.
- Private recorder file: ASCII `EEG-WIT`, byte `01`, then N × (blind:Fr, 500 slot:u32). This is a test reference witness, **never** an observer input or deployment transport. The optional public-replay HDL bridge reads it solely to check exactly the same simulation vectors.

## Trust and disclosure

The signature rejects substituted roots but cannot repair a dishonest sampler, fabricated timing or compromised signer. A valid proof does not hide session length, policy, total, identity or timing metadata. Extreme totals, very small sessions, repeated sessions or auxiliary information can expose individual outcomes. This repository implements **one approved question**, not arbitrary verifier scripts. Do not accept unreviewed policies or keys, silently skip windows, or use a laptop holding the private witness as an adversarial observer. Production assumptions include secure acquisition, randomness, key lifecycle, protected memory/accelerators and an independently approved setup; the development Groth16 generator has no trusted-ceremony claim.
