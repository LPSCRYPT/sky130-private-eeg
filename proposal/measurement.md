# Silicon measurement plan

**Requested bench path.** Public fixtures only; no electrodes. Request two dedicated digital **inputs**, `clk` and `strobe`, from one pattern generator. The selected slot uses 12 held controls (`rst`, `op[2:0]`, `din[7:0]`) and 11 sense bits (`dout[7:0]`, `busy`, `ready`, `root_valid`). Confirm assignment, mux, current limit, sequencing and approved protected 3.3 V pad ↔ 1.8 V core translation before drive. Never apply 3.3 V to core logic. The [prior IHP harness](https://opencircuitdesign.com/chipalooza/challenge-2.html) used SPI; the [Sky130 resource count](https://opencircuitdesign.com/chipalooza/rules-4.html) guarantees neither write speed nor edge timing.

| Test | Stimulus and acceptance |
|-------------|---------------------------------------------------|
| Slow known answer | At 1 MHz, sample reset on a rising edge, load 50 header bytes and start. Send 500 slots 22,000 clocks apart: three byte loads then PRESENT, spaced 5,500 clocks apart. For the missing-slot vector, stage `0xdeadbe` at slot 7 then issue MISSING instead. Keep strobe low during drain. Only after `(busy, ready, root_valid) = (0,0,1)`, address bytes 0–31 and read after each registered response. Reassemble little endian and compare all 32 bytes to `tests/reference-roots.txt` in order: index 0, index 1, index 0 with slot 7 missing. `tools/reference_roots.py` specifies all public inputs. |
| 250 Hz within one window | Repeat with a continuous clock: 22,000 clocks/tick at 5.5 MHz; 40,000 at 10 MHz; 48,000 at the 12 MHz nominal target. Require 500 ticks, all 499 intervals exactly 4 ms within clock calibration, and exact roots at each reported passing bin. No software waits or skipped slots. Log supply, temperature and repetitions per bin; repeat only at authorized extremes. |
| Finalization and recovery | At 22,000 clocks/tick, stop the clock low 212,992 rising edges after tick 499: valid must still be low; one more rising edge must publish the root. Slow polling alone cannot time this edge. Record the gap through readout and rearming; 212,993 clocks already cost 38.73 ms at 5.5 MHz. Mid-window reset, a partial sample followed by PRESENT, or a tick while busy but not ready must leave no valid root; require a fresh known answer after reset. |

**Can the pins deliver the schedule?** An all-present window needs **2,083** strobes: 51 header/start, 2,000 acquisition, 32 read addresses. The generator pulses across one rising edge per command; a held-high strobe repeats it. At 250 Hz, schedule the harness writer against the same trigger: four settled presentations per 4 ms, one per ms. Record write completions against pulses and budget mux settling and pad-to-core skew; average bus rate is insufficient. A missed write deadline or unresolved setup/hold makes that rate test **inconclusive**. A wrong root, missing valid or rejected tick with verified stimulus is a **failure**. Slow success is not a 250 Hz pass.

**Power.** At the 12 MHz target, measure average active rail power from START through root publication with a 250 Hz public fixture; report rail voltage, current, integration interval and uncertainty. Measure idle at the same clock, rails, temperature and other-slot state. The active-minus-idle difference is not total active power. Judge the ≤20 mW average active target only on an isolated macro supply, including uncertainty; a shared rail leaves that target **unresolved**.
