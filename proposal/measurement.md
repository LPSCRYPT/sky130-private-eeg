# Silicon measurement plan

**Question.** Does the selected slot emit precisely the specified commitment to every ordered slot of a 500-slot window, at the target sample rate, without a normal raw-read operation? Test data, including blinds, are public synthetic fixtures. Do not connect electrodes or people.

1. **Before power.** Confirm the assigned wrapper, pin multiplexing, pad voltage domain, register-write bandwidth, power sequencing, current limit and approved operating range with the harness owner. Do not connect a 3.3 V generator to core logic. Scope clock and command setup/hold at the receiver, not just the generator. If the control-register fabric cannot issue strobes at the required rate, obtain an approved clock/test path or report the measurement unavailable. No physical pad numbers are assumed.
2. **Known-answer at nominal.** Select only this slot. Hold synchronous reset over active clock edges, load a public header and send 500 slots at 250 ticks/s. Read the 32 result bytes and compare all bits with the independent integer oracle. Exercise both rails, both signs, zero, and missing slots. Repeat with a one-bit input change, swapped slot order, a different blind and index; predict each root before reading silicon. Record roots, cycle counts and supply conditions. A plausible but unequal digest is a failure.
3. **Errors and reset.** Reset during configuration, multiplication, acquisition and after a valid root. An incomplete or overrun window must not produce a valid root. Confirm a fresh window subsequently agrees with the oracle. Exercise malformed byte sequences and a noncanonical field element. Drive absent slots with distinct electrical data values: the committed missing slot must be canonical zero. Measure status pin behavior including response to an early tick. Check all public read operations; there must be no sample, per-window quality flag, or private opening readback. This is interface validation, not a leakage certificate.
4. **Operating envelope.** At nominal voltage and temperature sweep clock upward until digest mismatch, timing error, or instrumentation limit. Count cycles from the last sample to root-valid and clock edges per accepted tenth sample. At each authorized supply/temperature extreme repeat known-answer and reset tests. Report observed pass/fail limits separately from Liberty/STA predictions. Include trigger uncertainty, clock calibration, supply at the DUT and confidence limits on repetitions. Shared-rail current measured with this slot active versus idle is a board-level difference, not an isolated macro measurement.
5. **Laptop demonstration.** Independently verify a signed complete ordered manifest and the aggregate proof bundle with the preapproved verification and recorder keys. Test wrong challenge, wrong count, changed data/window order and missing proofs. Logged synthetic bench roots can test interoperability, but the shuttle harness deliberately exposes stimulus: it is not a source of trusted human data.

**Later sign-off.** Reusable standalone and separate slot layouts; DRC/LVS; extracted timing over foundry process/voltage/temperature corners, hold and reset behavior, frequency and area compared with slot allocation; power analysis and post-silicon plots with raw reproduction commands. Root mismatch, resource overflow or missed throughput is a failed gate, not permission to drop slots. No layout, routed wrapper, measured silicon, side-channel, scan, debug, fault-injection or key-provisioning qualification is claimed.
